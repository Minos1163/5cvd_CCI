## 一、检验本身的五个方法问题(先修,再引用)

### 1.1 基线与总体的成本构成不匹配,"所有 lift 为负"不能直接引用

报告的 `lift = E[R_net(分档)] − E[R_net(随机基线)]`,基线为 −0.193。但看全表:

```
< 68 分档(n=56,278,基本就是全体):   E[R] = +0.002   E[R_net] = −0.272   lift = −0.078
随机基线(n=14,014):                  E[R_net] = −0.193
```

`<68` 档几乎等于全体决策,而基线按定义应该和全体同分布(同标的、同日、随机时刻),两者的 `E[R_net]` 不应差 0.08。差距最可能来自**基线的 `stop_pct` 构成与全体不同**(报告写的是"取该块内随机一条决策的值",且每块最多 20 个样本,块与块被等权):`E[R_net] = E[R] − 0.002/stop_pct`,基线若平均 `cost_R` 低约 0.08,就能整体解释这个差距。换言之,**"每个分档 lift 上界都 <0"在很大程度上是成本构成差异,而不是信号质量差异**。

在没排除这一点前,不能说"分数越高越差"。毛边际口径下看(不受基线影响):

| 分档 | n | 毛 `E[R]` | 解读 |
|---|---:|---:|---|
| ≥92 | 27 | −0.333 | 有效独立片段极少,不下结论 |
| 82–92 | 969 | −0.039 | 与 `<68` 档的 +0.002 差 0.04,在噪声内 |
| 78–82 | 1,483 | −0.074 | 同上 |
| 68–78 | 7,522 | −0.014 | 同上 |
| <68 | 56,278 | +0.002 | — |

**更准确的表述是"分数与结果之间没有关系(平坦)",而不是"越高越差"。**

**修法(Task L1):**

```python
# 配对安慰剂:每条决策配一个"同标的、同日、同方向、同 stop_pct、随机 bar"的对照
for row in decisions:
    placebo = Row(symbol=row.symbol, date=row.date, side=row.side,
                  stop_pct=row.stop_pct,           # 直接复制,成本构成完全一致
                  ts=random_bar(row.symbol, row.date))
# lift 同时报告两个口径:
#   lift_gross = E[R] − E[R_placebo]        (不含成本,纯择时效应)
#   lift_net   = E[R_net] − E[R_net_placebo] (配对后成本相同,应与 lift_gross 几乎相等)
# 若两者差异 > 0.01,说明实现仍有成本构成问题
```

### 1.2 成本假设(20bps 往返)需要与纸面账户实际记账核对

标注用 `round_trip = 2×(5 fee + 5 slippage) = 20bps`。参考交易所公开费率:Binance U 本位合约普通用户 maker 0.02% / taker 0.05%,使用 BNB 付费有 10% 折扣,所以"fee 5bps/边"相当于全部按 taker,"slippage 5bps/边"是额外假设。20bps 作为压力口径合理,但**是否等于纸面账户实际扣的成本**需要核对——手边数字有一处对不上:

| 来源 | 数字 |
|---|---|
| 归因文档:手续费 + 滑点合计 | 20.98 USDT / 31 笔(每笔 0.68) |
| 若入场总名义为 N,往返成本 bps = 20.98 / N | N=20,000 → 10.5bps;N=30,000 → 7.0bps;N=40,000 → 5.3bps |
| 按 direct 约 1,850、probe 约 1,400、q1 约 60 的名义粗估 N | 约 30,000–35,000 → **约 6–7bps** |
| 报告标注假设 | 20bps |

粗估(名义由"单笔止损亏损 ÷ 止损幅度"反推,误差可能达到 2 倍)显示,**纸面账户实际记的成本可能只有 20bps 的 1/3 左右**;按费率一致性反推(5bps/边的 fee 对应的总名义仅约 10,500)则相反地显示名义偏小。两种口径互相矛盾,说明至少有一个量(费率、名义或记账方式)我们没有读对。

这件事决定报告标题结论的量级:

| 往返成本假设 | 平均 `cost_R`(按报告的止损分布) | 对应 `E[R_net]`(毛边际 ≈0) |
|---:|---:|---:|
| 6bps(纸面实际可能值) | 0.08 | ≈ −0.08 |
| 10bps(纯 taker 费,无滑点) | 0.14 | ≈ −0.14 |
| 14bps | 0.19 | ≈ −0.19 |
| 20bps(报告口径) | 0.27 | ≈ −0.27 |

**要求(Task L2):** 从成交记录直接反算每笔的实际 `fee_bps`、`slippage_bps` 与名义,给出分标的分布;检验报告同时给出 6 / 10 / 20bps 三条曲线。同时要区分两个问题:"纸面账户为什么亏"(用纸面记账的成本)与"这套东西上实盘能不能赚"(用实盘预期成本)——两者的成本口径不同,报告里混用了。

### 1.3 有效样本量与可检测的最小边际

66,279 行不是 66,279 个独立样本:

- 决策每 15 分钟一条,标注窗口 32 根,相邻样本强重叠,独立片段上限约 66,279 / 32 ≈ **2,070**;
- 16 个标的之间高度相关(加密资产共同 beta),再打折后有效独立片段大约在 **500–2,000** 的量级(这是量级估计,不是实测,应该用块 bootstrap 报告的实际有效数替换)。

据此,在 80% 功效、单侧 5% 下能检测的最小毛边际约为:

| 有效独立片段 | 命中率标准误 | 毛 `E[R]` 标准误(σ≈1R) | 最小可检测 `E[R]` |
|---:|---:|---:|---:|
| 500 | 2.2pp | 0.045 | **0.11** |
| 1,000 | 1.6pp | 0.032 | 0.08 |
| 2,000 | 1.1pp | 0.022 | 0.06 |

**怎么读:** 这份检验能排除"全体决策存在 ≥0.06–0.11R 的毛边际",但**不能排除更小的边际**。好消息是,在 15m 周期、20bps 成本下,小于 0.1R 的边际本来就不够付成本(平均 `cost_R` 0.27),所以"没有可测量的边际"对"能不能盈利"这个问题已经足够回答。但对高分子集(`≥92` 仅 27 条)和各象限、各方向的切分,功效远不足,这些切分的结论都应标注"功效不足"。

### 1.4 IC 的口径问题

| 问题 | 影响 | 修法 |
|---|---|---|
| "按日横截面"若是把当日所有决策池化后求 Spearman,则混入了日内时间序列效应,不是真正的截面 IC | 五因子 +0.0256 与池化分位单调下降(Q1 −0.013 → Q5 −0.039)互相矛盾,报告把它归因于"日间效应",但没有验证 | 改为**逐时间戳**的横截面(同一根 K 线上 16 个标的的分数与结果),再对时间取均值,用 Newey-West 或按日分块计算标准误 |
| IC 用 `R_net` 计算,而 `R_net = R − 0.002/stop_pct` 含有成本项;若分数与 `stop_pct` 相关(ATR、Fib 距离都可能影响止损幅度),IC 会混入"分数-成本"相关 | 可能制造或抵消信号 | 用**毛 `R`**算 IC,并按 `stop_pct` 分层或把 `stop_pct` 作为协变量 |
| 22 天、16 天为正,单侧 p≈0.026,但同时看了两个分数、多个分档与切分,且 22 天连续、regime 相关 | 未做多重比较校正 | 报告所有被查看过的切分数量;用 Benjamini-Hochberg 或预先固定只看哪几个检验 |
| 只看总分,没有分量 | 五个分量符号相反时总分 IC 会被抵消 | 做分量 × 周期的 IC 矩阵(第 3.2 节) |

### 1.5 标注器的正确性保障

首版曾把做空的目标价写反(SHORT 命中率被算成 0.4%),修复后重跑——说明标注器没有自动化的正确性检验。建议加三条**不变式测试**,每次改动必跑:

```python
# 不变式 1:镜像对称。同一根 bar、同一 stop_pct,多头与空头的障碍互为镜像,
#          毛 R 应满足  R_long + R_short == 0(超时按各自方向的收盘价结算时同样成立);
#          双触及 bar 两侧都按 −1R 处理,此时和为 −2,单独计数。
# 不变式 2:构造一条单调上涨的合成序列,LONG 必先触达 +1R,SHORT 必先触达 −1R。
# 不变式 3:构造一条无漂移随机游走(固定种子),命中率应落在 50% ± 3×SE 内。
```

另外应披露:**超时(32 根未触及任一障碍)的占比与结算方式**。49.73% 的命中率是否"理论值"取决于超时如何处理——报告没有给出占比,宽止损档超时会更多,这会影响第 3.1 节的"宽止损更好"判断。

### 1.6 修正后哪些结论会变

| 结论 | 修正后预期 |
|---|---|
| 总体毛 `E[R]≈0` | **不变**(与基线无关,只依赖标注与对称障碍) |
| 六因子 IC≈0 | **不变**,用逐时间戳 + 毛 R 重算后仍应接近 0 |

## 二、这份报告真正证明了什么

### 2.1 毛边际为零时,出场、杠杆、冷却都改变不了期望符号

如果特征在 8 小时内对价格没有预测力(条件漂移≈0),价格过程近似鞅,则**任何有界的出场规则(止盈/止损/保本/时间止损/追踪)的毛期望仍是 0**(可选停时定理),净期望恰好是 `−成本`。杠杆与每 R 风险只是线性缩放。这意味着此前评审与评审包里的一大批动作,在当前证据下**对期望符号无效**:

| 此前提出的动作 | 在"毛边际≈0"下的作用 |
|---|---|
| E1 出场结构 A/B(保本 1.5R、1R:2R 等) | 只改变分布形状与成本,不改变期望符号 |
| 杠杆映射、每 R 风险下调 | 只缩放亏损;纸面账户无资金风险,价值仅限于"学得更快"而非"亏得更少" |
| 冷却审计、跨日标的记忆、标的熔断 | 减少笔数 → 减少成本;不是 alpha |
| 4h 一票否决 | 先用标注验证;若 4h 方向对 8h 结果无预测力,则无用 |
| LONG offset 调整(D1) | LONG/SHORT 的 `E[R]` 相同,偏置没有数据支持,调不调都不改变期望 |
| 双峰 R 分布、保本止损吞噬 1–2R | 对期望符号无影响,可降为描述性现象 |

**一个必须补的检验:"IC 期限结构"。** 上面的论证要求"各子周期都没有漂移",而报告只看了 ±1R/8h 的聚合结果。若某分量在 1–2 根 K 线内有正漂移、之后被反转抵消,聚合 `E[R]` 会≈0,但短周期出场可以捕捉它。建议对每个分数(及分量)输出 1、2、4、8、16、32 根 K 线的毛前向收益与 IC 曲线——这是廉价的,且是"出场规则是否仍有价值"的决定性证据。

### 2.2 实盘与标注的一致性

| 来源 | 单笔期望 |
|---|---|
| 31 笔实盘(归因文档,R 为近似量) | `E[R] ≈ −0.22`(标准误约 0.18) |
| 标注(随机入场等价,20bps) | `E[R_net] ≈ −0.27` |

两者在误差内一致,说明**系统实盘表现与"零边际 + 成本"的预期大致吻合**,没有证据表明出场结构在额外吞噬信号——但 31 笔的标准误太大,这只是"没有被推翻",不是"已验证"。

### 2.3 边际要多大才够付成本

在"按分数取头部 q 比例入场、分数与结果近似二元正态、`σ_R≈1`"的粗略模型下,`E[R] ≈ IC × E[z | 头部 q]`(头部 20% 的 `E[z]`=1.40,10%=1.76,5%=2.06)。使 `E[R] ≥ cost_R` 所需的 IC:

| `cost_R` | 对应情形(往返 bps / 止损) | 头部 20% 所需 IC | 头部 10% | 头部 5% |
|---:|---|---:|---:|---:|
| 0.05 | 10bps / 2% 止损 | 0.04 | 0.03 | 0.02 |
| 0.10 | 10bps / 1% 止损 | 0.07 | 0.06 | 0.05 |
| 0.15 | 10bps / 0.67% 止损 | 0.11 | 0.09 | 0.07 |
| 0.27 | 20bps / 0.74%(现状均值) | **0.19** | 0.15 | 0.13 |
| 0.40 | 20bps / 0.5% 钳位 | **0.29** | 0.23 | 0.19 |

**这张表是本文最重要的一张。** 它说明:

1. 在现状成本结构下,需要 0.13–0.29 的 IC,15m 技术特征不可能达到(截面 IC 达到 0.05 通常就算相当好);
2. 把 `cost_R` 压到 0.05–0.10 以下,所需 IC 降到 0.02–0.07——**与五因子观测到的 0.0256 同一量级**。这不是说五因子已经够用(它的 IC 本身还不可靠),而是说**降成本才是把问题从"不可能"变成"边缘可能"的杠杆**,调分数门槛不是。
3. `cost_R = 往返成本 / 止损幅度`,因此要么降成本、要么放宽止损(或等价地,延长周期、减少换手)。这两条路都与"90–120 笔/30 天"冲突,目标必须重写。

### 2.4 对"重做入场"的重新表述

报告的判据落在"入场重做"一行,我同意。但"重做"要避免两个陷阱:

- **陷阱一:在同一问题设定里换个特征集再来一遍。** 15m / 0.5% 止损 / 20bps 的设定下,即使特征换成五因子,IC 要到 0.2 才够,这是设定问题,不是特征问题。
- **陷阱二:把"重做"理解为调门槛、调权重。** 门槛只改变样本量,权重(按 IC 定权)在 IC≈0 时就是在拟合噪声。

## 三、建议:三条线并行

### 3.1 成本线(降低 `cost_R`,不制造 alpha)

**A1 核对并分解真实成本(Task L2)。** 输出每笔 `fee_bps`、`slippage_bps`、`notional`,按通道/标的汇总;并列出三种情景:

| 情景 | 入场 / 出场 | 往返费率 | 备注 |
|---|---|---:|---|
| 全 taker | taker / taker | 10bps(BNB 折扣后约 9bps) | 标注的下限成本 |
| 混合 | maker 入场 / taker 出场 | 7bps | 需评估未成交与逆向选择 |
| 全 maker | maker / maker | 4bps | 成交率与逆向选择问题最严重 |

再叠加滑点(分标的流动性分层)。**纸面账户若没有队列/成交率模型,就无法评估 maker 情景**,不应直接把 maker 费率写进纸面账户,否则会高估收益。

**A2 止损下限与周期。** 用报告的止损分布做粗算(若所有止损宽度被抬到下限,其余不变):

| 止损下限 | 平均 `cost_R`(20bps) | 平均 `cost_R`(10bps) |
|---:|---:|---:|
| 0.5%(现状) | 0.27 | 0.14 |
| 0.8% | 0.22 | 0.11 |
| 1.0% | 0.19 | 0.09 |
| 1.5% | 0.13 | 0.07 |
| 2.0% | 0.10 | 0.05 |

注意事项:① 这是毛机械效应,**每笔风险不变时名义更小,成本绝对额同比下降**,属于"少交易同样的风险";② 宽止损下 32 根的时限会让更多交易超时,标注与实盘都要用**按止损缩放的障碍**重做;③ 在毛边际为零的前提下,宽止损只会让亏得更少,不会盈利。

**A3 把 `cost_R` 作为独立的守门指标记账。** 报告建议"拒绝 `cost_R>0.15` 的入场"本身是合理的成本守门,但必须与 alpha 分开记账:KPI 里同时给出"毛边际"与"成本节省",避免把成本规避当作策略改进。
