## 三、因子诊断(为何评分失去区分力)

对窗口内 13,806 条决策的 6 个 `component_points` 做:①**标准化**(各因子除以满分权重,消除量级差异)②相关矩阵 ③PCA(SVD)。

### 3.1 PCA:6 个因子只有 2 个有效维度

| 主成分 | 特征值 | 解释方差 | 累计 |
|---|---:|---:|---:|
| PC1 | 1.722 | 28.7% | 28.7% |
| PC2 | 1.212 | 20.2% | 48.9% |
| PC3 | 0.895 | 14.9% | 63.8% |
| PC4 | 0.826 | 13.8% | 77.6% |
| PC5 | 0.719 | 12.0% | 89.6% |
| PC6 | 0.626 | 10.4% | 100% |

**Kaiser 准则(特征值 >1)只得到 2 个主成分**(PC1+PC2 = 48.9%)。剩下 4 个因子合计承载 50% 方差,其中大部分是噪声。

### 3.2 载荷:PC1 把四个因子捆成了同一件事

| 因子 | PC1 载荷 | PC2 载荷 |
|---|---:|---:|
| trend_ema_context | **-0.650** | -0.347 |
| cci_momentum_quality | **-0.633** | +0.419 |
| price_action_structure | **-0.582** | +0.238 |
| flow_cvd_confirmation | **-0.556** | +0.373 |
| fibonacci_location | +0.470 | +0.599 |
| risk_reward_geometry | -0.173 | **-0.601** |

- **PC1(28.7%)= "价格动能强度" ↔ "Fib 回撤位置"** 的对抗轴:`ema + cci + pa + cvd` 四个因子在同一个方向上同向加载(**它们测的是同一件事**),fib 反向。
- **PC2(20.2%)= "结构位置 ↔ 赔率"** 轴。
- 相关矩阵印证:所有 |Pearson r| < 0.43,表面"低相关",但 PCA 表明**低相关只是因为零膨胀稀释**——`cci` 归零率 49.7%、`pa` 34.8%、`rr` 17.7%(因子在多数时间无信号,相关性被 0 稀释)。

### 3.3 机制性根因(代码级证据)

`flow_cvd_confirmation` **并非 CVD**,其实现是(`src/signals/entry_chain_features.py`):

```python
signed = Σ_{最近 6 根 15m K 线} (+1 if bar.close >= bar.open else -1) × bar.volume
LONG: 1.0 if signed > 0 else 0.2      # 仅 4 个离散取值 {1.0, 0.5, 0.2, 0.0}
```

它是"最近 6 根 K 线涨跌方向的有符号成交量投票",与 `bar.close >= bar.open` 同源 → **与 ema/cci/pa 在信息上高度重叠**,这在 PC1 载荷上完全显形(四者同向加载)。策略里**实际没有订单流(CVD)维度**。

**更值得注意的是能力闲置**:项目**已经具备真 CVD 基础设施**——
- `src/data/cvd_builder.py::build_cvd`:用 `taker_buy_volume` 计算主动买卖差累加(真 CVD);
- `src/indicators/cvd.py::cumulative_cvd` / `cvd_delta`,且已接入 `indicator_engine.py`;
- `src/data/data_contract.py` 已契约化 `taker_buy_base_volume` / `taker_buy_quote_volume`。

**即:真 CVD 资产已建成,却未接入评分层**——评分使用的仍是退化代理。这使"F5 真实订单流"的重构成本远低于预期(接入而非新建)。

### 3.4 权重与信息量严重错配

| 因子 | 满分权重 | 归一化后 std(信息量) | 零值占比 | 离散档位 |
|---|---:|---:|---:|---|
| price_action_structure | **22** | 0.345 | 34.8% | 12/9/6 + 6/-4 + 3 |
| trend_ema_context | **20** | **0.187(最低)** | 0% | 8+7+5 三段台阶 |
| flow_cvd_confirmation | 18 | **0.381(最高)** | 0% | **4 档,伪 CVD** |
| fibonacci_location | 18 | 0.294 | 8.9% | 18/13/9/6/2 |
| cci_momentum_quality | 14 | 0.336 | 49.7% | 14/10/7/3/0 |
| risk_reward_geometry | **8** | 0.265 | 17.7% | **5/3.5/2/0(实际上限 5/8 = 62.5%)** |

两处硬伤:
1. `trend_ema_context` 权重 **20**(第二高),但归一化 std **0.187(最低)**——近乎常量,信息量最少却给了最大权重;
2. `risk_reward_geometry` 权重 8 且**代码上限只有 5.0**(`net_tp1_r >= 1.3 → 5.0` 即最高档),**永远拿不到满分**,等于被隐性降权到 62.5%×8 = 5。

## 四、归因结论(供评审)

1. **亏损主因是入场质量,不是仓位管理、不是离场规则、不是方向偏置**:
   - MFE 判据(28/33 笔 <1R)、初始止损 100% 亏损、方向两侧同亏、退出机制健康(高 MFE 全保住);
2. **风险预算未失效**:单笔最大亏损 -26.49(≈账户 0.26%),远低于 0.6% 预算 → 与 08-31 结论一致(非仓位大小问题);
3. **`main_probe` 通道是出血点**(85% 亏损),但根因仍是其入场质量,只是杠杆放大;
4. **评分体系已无区分力**(score 75→95 与结果无关),因子层的病因是:
   - **6 个因子实际只有 2 个正交维度**(PC1 = 动能四因子同源捆绑;PC2 = 位置 vs 赔率);
   - **`flow_cvd_confirmation` 是伪 CVD**(K 线方向投票),策略**缺失真正的订单流维度**;
   - **缺失波动率状态维度**(ATR% 只用于杠杆/止损 clamp,未进入评分);
   - **权重与信息量错配**(最高权重因子信息量最低;RR 因子天花板 62.5%)。

→ 支撑"重构为 5-6 个**正交**因子"的方向,设计方案见 `docs/2026-09-27-orthogonal-factor-redesign.md`。
