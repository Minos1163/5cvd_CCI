## 0. 一句话概述

AI300 是 Binance USDT 永续（市值排名 3–25）、15m 触发周期的多周期趋势跟随系统。核心是一个 **6 因子加权评分（满分 100）→ 分数阈值决定动作 → 四象限做环境标注 → 仓位按止损距离反推 → 三档分批止盈**。当前处于纸面（dry-run）阶段，从未提交真实订单。

## 3. 六个因子的精确定义

### 3.1 `trend_ema_context`（权重 20）

```python
gate_score      = 8.0 if ema200_gate.allowed else 0.0
ema50_score     = max(0, score_ema50_quality(side, ctx) + gate.penalty) * 7.0   # 仅当 gate 通过
momentum_score  = score_ema_momentum(side, ctx) * 5.0                          # 仅当 gate 通过
score = clamp((gate_score + ema50_score + momentum_score) / 20.0, 0, 1)
```

- **EMA200 闸门**：`ema200_gate_mode = "soft"`。soft 模式不否决，只施加 `penalty = -0.20` 的分值修正。
- 三个子项：闸门方向一致性 8 分、EMA50 排列质量 7 分、动量 5 分。
- **覆盖率**：9,287 条决策中该因子**无一为 0**（最低 8.0），说明 EMA200 从未完全否决。

**实测分布**：均值 14.68 / 上限 18.65（cap 20），零分率 0%，满分率 0%。

### 3.2 `flow_cvd_confirmation`（权重 18）

```python
def volume_flow_score(side, bars):
    signed = Σ over last 6 bars of (+1 if close>=open else -1) * volume
    if signed == 0: return 0.5
    if side == LONG:  return 1.0 if signed > 0 else 0.2
    return 1.0 if signed < 0 else 0.2
```

**这是二值函数，不是连续量**。只有三个可能取值：1.0（满分 18）、0.2（3.6）、0.5（9）。

- 语义：最近 6 根 15m K 线中，"实体方向 × 成交量"的净和是否与交易方向一致。
- **这是伪 CVD**：用 K 线实体方向代替真实 taker buy/sell 成交量。真实 CVD（`taker_flow_cvd`）在代码里存在但**未进入 live 评分链**。

**实测分布**（9,287 条）：`18.0` 占 **66.5%**，`3.6` 占 **33.5%**，无中间值。
**16 笔已成交全部落在 18.0 档**——它实际起的是准入门槛作用，而非排序因子。

### 3.3 `cci_momentum_quality`（权重 14）

CCI(20) 的标准实现：`(TP - SMA(TP,20)) / (0.015 × mean_deviation)`，其中 `TP = (H+L+C)/3`。

**离散五档**（按最新值 + 近 5 根形态判定）：

| 条件（SHORT） | 分值 | 标签 |
|---|---:|---|
| 近 5 根 min < −150 且近 4 根（除最新）max > −80 且 latest < series[-2] | **14.0** | 二次走弱（最佳） |
| 近 4 根 min < −120 且 latest > −80 | 0.0 | 假突破（否决） |
| latest < −150 | 0–3.0（线性递减） | 超卖衰竭 |
| −150 ≤ latest ≤ −100 | **10.0** | 健康 |
| −100 < latest < −50 且最新在下降 | **7.0** | 回调走弱 |
| 其他 | 0.0 | 不支持 |

LONG 侧镜像（100–150 为健康、50–100 回调走强、>150 衰竭）。

**实测分布**：均值 3.93 / 14，**零分率 50.3%**，满分率 5.6%。**这是区分度最高的因子。**

### 3.4 `price_action_structure`（权重 22）

三个子分相加，上限 22：

| 子项 | 分值 |
|---|---:|
| 结构（二次回测） | 12.0（`LOWER_HIGH_RETEST` / `HIGHER_LOW_RETEST`）或 9.0（突破回测）或 6.0（延续）或 0 |
| K 线形态 | 0–? （`_candle_score`，针形/吞没等） |
| 摆动趋势 | `_swing_trend_score`（摆动点高低点序列） |

**实测分布**：均值 7.36 / 22，**零分率 34.9%**，最高只到 21.0（从未满分）。

### 3.5 `fibonacci_location`（权重 18）

对 1h 与 15m 分别计算分形摆动点 → 斐波那契回撤/扩展位 → 按当前价所处区间打分。**先检查扩展 exhaustion 否决**：

```python
# SHORT: if price <= e1618 + tolerance → NO_TRADE (action_cap)
# LONG:  if price >= e1618 - tolerance → NO_TRADE
tolerance = ATR × 0.5
```

否决后 `action_cap = "NO_TRADE"`，直接禁止开仓（与分数无关）。

| 区间（SHORT） | 分值 |
|---|---:|
| price ≤ e1618 + tol | **0（NO_TRADE 否决）** |
| r382 − tol ≤ price ≤ r618 + tol | **18.0** 最优回撤 |
| r618 < price ≤ r786 + tol | 13.0 深度回撤 |
| e1272 − tol ≤ price < e1000 | 6.0 扩展区 |
| price < e1272 − tol | 2.0 惩罚 |
| 其他 / 无摆动点 | 9.0 中性 |

LONG 侧镜像。15m 若在 1h 基础上又贴近 15m 的 e1000 支撑，额外 −3.0。

**实测分布**：均值 10.53 / 18，零分率 9.0%，满分率 **25.7%**。

### 3.6 `risk_reward_geometry`（权重 8）—— **存在设计缺陷**

```python
stop_dist = clamp(ATR × 1.5, 0.5% × close, 3.0% × close)
tp1_dist  = stop_dist × 1.2              # TP1_R_MULTIPLIER = 1.2
net_tp1_r = (tp1_dist − close × 0.001) / stop_dist

# 基础分
if   net_tp1_r >= 1.3: score = 5.0
elif net_tp1_r >= 1.1: score = 3.5
elif net_tp1_r >= 0.9: score = 2.0
else:                  score = 0.0

# 反向结构惩罚
if 0 < opposition_dist < 0.7 × stop_dist: score -= 3.0
elif 0 < opposition_dist < stop_dist:     score -= 1.5

# ATR 区间加分
if   0.008 <= atr_pct <= 0.025: score += 3.0
elif 0.005 <= atr_pct <  0.008: score += 1.5
elif atr_pct > 0.030:           score += 1.0

final = clamp(score, 0, 8)
```

**缺陷**：`net_tp1_r = 1.2 − 0.001/stop_pct`。当 `stop_pct ∈ [0.5%, 3.0%]` 时，该式取值范围是 **[1.000, 1.167]**：

| stop_pct | net_tp1_r | 落入档位 |
|---:|---:|---|
| 0.5% | 1.000 | 2.0 分 |
| 1.0% | 1.100 | 3.5 分（边界） |
| 2.0% | 1.150 | 3.5 分 |
| 3.0% | 1.167 | 3.5 分 |

- `>= 1.3`（5.0 分）**数学上不可达**
- `>= 1.1`（3.5 分）需要 `stop_pct ≥ 1.0%` —— 注意方向：**止损越宽越容易拿到**
- `>= 0.9`（2.0 分）**永远成立**

> **更正（2026-11-14 21:55）**：本文早先版本写"`>=1.1` 仅在 `stop_pct ≤ 1.0%` 时可达"，方向写反了。`net_tp1_r = 1.2 − 0.001/stop_pct` 对 `stop_pct` 单调**递增**，因此是"止损越宽、净 R 越高"。

**这比"满分不可达"更严重**：该因子对止损宽度是**单调正向**的，实际在奖励宽止损。止损 0.5% 只能得 2.0 分，止损 1.2% 就能得 3.5 分，与"风险回报是否划算"无关。当一个因子对风险敞口单调给分时，它会系统性把候选推向"止损更宽"的方向——而宽止损意味着单笔亏损更大（除非同步缩小名义，但 `leveraged_cap` 又会反向作用，见 §7.1）。

**本窗口实证（16 笔成交）**：

| stop_pct | rr 得分 | 笔数 |
|---|---:|---:|
| 0.66–0.97% | 0.5 – 3.5 | 5 |
| 1.01–1.14% | 5.0 | 5 |
| 1.25–1.46% | 6.5 | 6 |

**Spearman(stop_pct, rr_score) = +0.859（n=16）**

分段如此整齐，是因为 `net_tp1_r` 只有 2.0/3.5 两档可达，再加上 `atr_pct ∈ [0.8%, 2.5%]` 的 +3.0 加分。**"风险回报几何"这个 8 分权重，实测是"止损宽度"的代理变量，不是风险回报质量的度量。**

**后果**：这个"风险回报几何"因子的基础分恒为 2.0–3.5，实际得分几乎全部来自"ATR 是否落在 0.8%–2.5%"。**8 分权重实际是一个波动率筛选器。**

**实测分布**：均值 2.29 / 8，零分率 23.9%，**最高只有 6.5**（= 3.5 + 3.0，即 stop ≤1% 且 ATR 在区间），**满分不可达**。

## 7. 仓位与杠杆

### 7.1 仓位三约束取最小

```python
risk_pct = direct_risk_pct(0.6%) if DIRECT else probe_risk_pct(0.15%)

raw_notional        = equity × risk_pct / stop_pct
leveraged_cap       = equity × max_single_trade_risk_pct(0.75%) / (stop_pct × leverage)
remaining_exposure  = (max_symbol_exposure_pct − current_exposure_pct) × equity

final_notional = min(raw_notional, leveraged_cap, remaining_exposure)
binding_cap    = 上述三者中最小者
```

`risk_first_sizing_enabled = False`（默认关闭），所以走上面这套旧口径。

**这里有一个方向性的设计问题**：`leveraged_cap` **除以 leverage**。杠杆越高，这个上限越小，于是"杠杆越高 → 名义仓位越小 → 单笔实际风险越小"。杠杆成了**风险收缩器**而不是放大器。代码注释里也承认这一点，并提供了 `risk_first_sizing_enabled` 开关（打开后改为风险定额），但**默认关闭，生产配置未启用**。

### 7.1.1 实测证据（2026-11-08 → 11-14，16 笔）

| 通道 | 杠杆 | 实际风险 | 占权益 | 配置声称 |
|---|---:|---:|---:|---:|
| `main_direct` | 4x | **18.75 USDT（恒定）** | 0.188% | 0.6% |
| `main_direct` | 5x | **15.09 USDT** | 0.151% | 0.6% |
| `main_probe` | 3x | 15.03–15.06 | 0.150% | 0.15% |
| `q1_trend_launch` | 1x | 0.41–0.90 | 0.006% | — |

推导：`风险 = leveraged_cap × stop_pct = equity × 0.0075 / leverage`。杠杆 4x → 18.75，5x → 15.0。

**两个后果**：

1. **DIRECT 的实际风险只有配置值的 31%**（0.188% vs 0.6%）。`raw_notional` 本应给出 60 USDT 风险，但 `leveraged_cap` 更小，成为 binding cap。要提高实际风险必须先改这一项，否则提高 `direct_risk_pct` 会被同一项抵消。
2. **5x 反而不如 4x**：杠杆从 4 升到 5，风险从 18.75 降到 15.0。这直接违反"高置信度给更高杠杆"的设计意图。

**`q1_trend_launch` 通道的名义只有 62–110 USDT**（主链的 1/20），5 笔合计净 −1.22 USDT，等于空转。

### 7.2 杠杆选择

```python
if action not in {PROBE, DIRECT}: return 0
if rolling_sharpe_20 < 0:            return 2   # 连亏保护
if atr_pct > 0.03:                   return 3
if atr_pct > 0.015:                  return 4 (DIRECT) / 3 (PROBE)
if score >= 90 and DIRECT:
    if fib_pa_5x_requirements_met:   return 5
    else:                            return 4   # FIB_PA_5X_REQUIREMENTS_FAILED
return 4 (DIRECT) / 3 (PROBE)
```

5x 的附加要求：`fib ≥ 13/18`、`pa ≥ 9/22`、`cci ≥ 7/14`、`rr ≥ 4/8`。

### 7.3 止损距离

```python
stop_dist  = clamp(ATR × 1.5, 0.5% × close, 3.0% × close)
stop_pct   = stop_dist / close      # 上限另受 max_stop_pct = 4% 约束
```

**注意**：`risk_reward_geometry` 里用的 `stop_dist` 与建仓时用的止损是**同一套推导**。若只改一处（比如只放宽 RR 里的 clamp），会导致"评分按 0.5% 算、实际按 1.0% 出场"，单笔风险翻倍。这一点在 10-31 的评审里已被记为历史 bug。

## 8. 出场

### 8.1 主账本（`paper_exit_mode = legacy`）

| 指标 | 值 |

- 出场层可优化空间约 1.2R（仅 2 笔属于浮盈回吐）

**出场三个旋钮合计可支配空间约 0.005R，而净 E[R] 是 −0.20 ~ −0.31R**。要靠出场救回来需要毛 E[R] ≥ +0.19R。
