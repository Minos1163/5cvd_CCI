# Stage B：1h 上重算六因子 —— 裁决

> 2026-10-19。与 Stage A（`docs/analysis/stop_floor_cost_tf_uplift_2026-10-19.md`）严格区分：
> **Stage A = 15m 因子 + 1h 出场（只测成本上限）**；**Stage B = 1h 因子 + 1h 出场（测真 alpha）**。
> 复现入口：`scripts/analysis/six_factor_1h_20261019.py`；产物 `reports/analysis/six-factor-1h-20261019/`。

## 0. 结论

**1h 也不产 alpha。** 预登记的五道门里 G1、G3、G4 全部未过，G5（进 Stage C）为 false。

一句话：**把六因子搬到 1h 上重算，确实换了一套几乎不相关的分数（Pearson 0.30），但那套分数对远期 R 的排序能力同样是 0——而且十分位层面是负的（ρ −0.24 ~ −0.66），最高分位 `E[R]` 全部为负。**

因此「1h / 4h」这条周期维度到此关闭，不再做 4h。

## 1. 设计与控制变量

锚点 = 段内历史 ≥ 240 根 1h bar 的每一个小时（段按 `Δts == 3600` 切）。五个臂共用**同一批锚点、同一 labeler、同一止损规则、同一成本**，逐级只加一个变化：

| 臂 | 六因子来源 | ATR% 口径 | 高周期结构 | side |
|---|---|---|---|---|
| A0 `base_15m` | 日志里该小时最后一根 15m 的 `score_detail.total_score` | — | — | 日志 |
| B1 `h1_raw` | 1h 重算 | 绝对 | 无 | 日志（固定） |
| B2 `h1_norm` | 1h 重算 | **归一到 15m 量级（×0.5）** | 无 | 日志 |
| B3 `h1_norm_4h` | 1h 重算 | 归一 | **4h fib** | 日志 |
| B4 `h1_e2e`（主口径） | 1h 重算 | 归一 | 4h fib | **1h 自推** |

固定项：`WINDOW_1H=240`（对齐线上 `--public-kline-limit 240`，EMA 路径依赖必须固定）、`WINDOW_4H=60`、`horizon=8`、`cost_breakeven_bars=2`、ladgex 出场、往返 20bps、止损 `clamp(ATR_1h×1.5, 1.5%, 4%)`。

三种刻意规避的陷阱：① `fib_1h` 与 `fib_15m` 绝不传同一条序列（`score_fibonacci_location` 会对两者各做一次 SHORT 支撑邻近 −3）；② 4h 结构只用「入场时点已收盘」的 bar（`h4 + 4h ≤ ts + 1h`）；③ 经济学结论只用 non_overlap 子集。

| B2（1h 归一） | 26,237 | +0.0128 | 0.1160 | −0.1032 | [+0.0066, +0.0192] |

## 4. 三条可以带走的事实

**① 换周期确实换了信息，但换来的信息同样无用（甚至是反的）。**
同锚点配对：A0（15m 分）vs B4（1h 分）**Pearson 0.299 / Spearman 0.292，平均绝对差 13.7 分**。两套分数几乎不相关——所以这不是"同一套分数换了算法"，而是真的换了信息源。

但两套分数对 R 的排序能力都不成立：行级 ρ −0.011 ~ −0.058（3 万级样本上这个量级就是噪声），**十分位 ρ 全为负**（−0.24 ~ −0.66），最高分位 `E[R]` 全为负。

A0 的十分位 ρ = −0.539 还顺带做了一次交叉验证：**15m 的六因子分在 1h 出场口径上同样是反向的**，与此前 66,279 条决策的前向标签结果（六因子 IC 0.0012、各分档 lift 的 80% 上界全部 < 0）方向一致。两套独立的出场口径、两套独立的数据切法，结论一致。

**② 成本已经不是主要矛盾，缺口在 alpha 本身。**
1h 止损中位数 **1.59%** → `cost_R = 0.112`（20bps），比 15m 的 0.295 降了 2.6 倍。但 `E[R]` 只有 **0.0035**：

| 成本口径 | 盈亏平衡所需 `E[R]` | 实测 | 缺口 |
|---|---:|---:|---:|
| 20bps | 0.1254 | +0.0035 | −0.1219（36×） |
| 11bps | 0.0690 | +0.0035 | −0.0655（20×） |
| 7.75bps | 0.0486 | +0.0035 | −0.0451（14×） |

**③ 止损宽度再次被证明不是 alpha 来源。**
把下限从 1.5% 放开到 0.5%（7,978 行受影响）：`E[R]` **+0.0035 → +0.0035**（毛利几乎不变），`cost_R` 0.112 → 0.144。窄止损只抬成本，不改毛利——与 15m 上 27 场景网格的结论完全一致。

样本构造敏感性（主口径）：全样本 +0.0035 / 非重叠按已实现持仓 −0.0017 / 非重叠固定 8h 冷却 +0.0036 / 剔除 fib 阻断 +0.0025。**四种构造都在 0 附近**，不是样本构造造出来的结论。

## 6. 顺带修掉的一个假阴性 bug（影响所有历史 labeler 数字）

代码评审发现 `fwd_label_20261019.label_ladder` 的一处仓位记账缺陷：**Q3 减半（`remaining *= 0.5`）之后，TP 仍按原始 40/35/25% 扣减，剩余仓位会变成负数**，`remaining × _pnl(exit)` 随之变成反向仓，把趋势赢家记成亏损单。线上 `paper_trading.py:322` 用的是 `min(remaining, tp_fraction)`，研究版没有这个 clamp。

已修：`fraction = min(remaining, TP_FRACTIONS[i])`，并在 `_result` 加 `0 ≤ remaining ≤ 1` 的断言。

实测影响：A0 的 `E[R]` +0.0070 → +0.0107（此差值同时含 4h 边界修正），**量级 0.002–0.004R，不改变 Stage A / Stage B 的任何判据**——各结论的缺口都在 0.02–0.12R 量级。

登记为 `2026-10-19-RELABEL`：`tf_uplift` / `stop_floor` / `edge_scan` / `cost_sensitivity` / `ladder_consistency` 的既有数字在修复前算出，引用前需重跑。

## 7. 停止条件

按预登记 G5，本轮到此为止：

- **不再做 4h**（周期维度的边际收益已被算术锁死：4h 的 `cost_R` 更低，但 Stage B 证明 1h 的 `E[R]` 只有 0.0035，4h 不会凭空产生 alpha）
- **不再调止损宽度**（毛利对它不敏感，第 4 节③）
- **不再调成本档**（7.75bps 已是执行层上限，仍需 14 倍 alpha）
- **不再加入场条件扫描**（113 条候选零条通过 OOS，见 `2026-10-19-EDGESCAN`）

剩下唯一没被动过的变量是**六因子本身的构造与权重**（trend 20 / cvd 18 / cci 14 / pa 22 / fib 18 / rr 8）。若还要继续，必须从「重做因子」而不是「调周期/成本/闸门」入手——而这需要新的假设来源，不是再跑一遍同样的数据。
