### 1.2 最重要的问题:安慰剂很可能存在前视泄漏

**v2 的构造:** 同 symbol、同 UTC 日、同方向、同 `stop_pct`,时点在当日随机。结果 `E[R] = +0.0704`,被解读为"方向对、时点随机"的毛期望,即"方向 edge"。

**问题:** 决策里的方向由过去信息决定(链路中 `direction_from_history()` 用最近 4 根 1h 收盘变化是否超过 ±0.3% 判定多/空)。当安慰剂时点 `t′` 早于该决策的时点 `t`,以 `t′` 为入场、向前 32 根的标注窗口**会包含那段促成方向判断的价格走势**:

```
决策时点 t:    过去 4h 上涨 0.4%  →  方向 = LONG
安慰剂时点 t′ = t − 3h:  入场后的前向窗口 [t′, t′+8h] 包含了 [t−3h, t] 的那段上涨
→ LONG 的前向 R 机械地偏正,而这个"方向"是在看到那段走势之后才定的
```

这是教科书式的前视偏差:方向由未来(相对 `t′`)信息决定。0.07R 的量级(≈ 4.8bps,相对于 0.4% 的触发阈值)与这种机械重叠完全相容。

**为什么我怀疑它,而不仅是"可能":** v2 自己的两组证据互相冲突。

| 证据 | 含义 |
|---|---|
| 安慰剂 vs 实盘 → 择时 −0.07R,在 ±1R / 8h 目标口径上 | 若为真,h=8–32 的 IC 应在 −0.05 量级(`E[R] ≈ IC × σ × 1.4`,σ≈0.95) |
| v2 §1.4:h≥8 的 IC 不再显著 | 与上一条冲突——除非 MDE 实际远大于报告值(第 1.3 节) |

**零成本的判别(T0a-0,10 分钟,数据已有):** 把 `placebo_pairs.csv` 按 `t′−t` 分桶看 `E[R_placebo]`:

| `t′ − t` | 泄漏假说预测 | 真实方向持续性假说预测 |
|---|---|---|
| < −8h(窗口够不到 `t`) | ≈ 0 | ≈ 0 或弱正 |
| −8h ~ 0(窗口覆盖促成方向的走势) | **显著为正,越靠近 0 越大** | 弱正 |
| 0 ~ +8h | ≈ 0 | **正**(方向在 `t` 之后仍持续) |
| > +8h | ≈ 0 | 衰减 |

泄漏的签名是"正效应集中在 `t′ < t` 且在 `t` 附近最强,`t′ > t` 时消失"。如果 `t′ > t` 的桶里 `E[R]` 仍显著为正,方向持续性才可能是真的。

**干净的安慰剂(T0a-1):**

```python
# A. 陈旧方向:只抽 t' > t,方向取自 t(无前视;测的是"方向在 t 之后的持续性")
# B. 自洽规则:在随机 t' 重新按同一规则计算方向(direction_from_history 用 t' 之前的数据),
#              stop_pct 取 t' 当时的值——测的是"方向规则 + 随机择时"的毛期望,
#              与实盘(方向规则 + 评分择时)的差才是真正的择时项
```

构造 B 是干净的分解:`实盘 − B = 择时`,`B − 0 = 方向规则本身的毛边际`。我预期 B 的毛 `E[R]` 接近 0(方向规则是 1h 趋势追随,在 15m/8h 上没有理由有边际),**那样的话方向 edge 与择时 −0.07R 会一起消失,整个分解塌缩为"没有边际"**——与 10-19 检验报告的第一结论一致。这是先验,不是结论。

### 1.3 "择时层显著为负":显著性与 MDE / neff 不自洽

v2 §1.4 给出:

| h | IC | MDE | neff | 按 `SE=1/√neff` 的 t(双侧 p) | 按 `MDE/2.8` 反推的 SE 的 t |
|---:|---:|---:|---:|---|---|
| 1 | −0.0281 | 0.0176 | 2,856 | −1.50(0.13) | −4.5 |
| 2 | −0.0226 | 0.0201 | 2,195 | −1.06(0.29) | −3.2 |
| 4 | −0.0226 | 0.0217 | 1,927 | −0.99(0.32) | −2.9 |

三行的 `MDE × √neff` 都≈0.94;而 80% 功效、5% 水平的正确值是 2.49(单侧)至 2.80(双侧)。也就是说:**要么 neff 被低估了约 7 倍(MDE 对、neff 错),要么 MDE 被低估了约 2.6 倍(neff 对、MDE 错)**。BH q=0.0000 的结论只在第一种情形下成立;在第二种情形下,h=1 的 IC 不显著,h=2/4 更不显著。

**要求:** 披露 IC 标准误的实际来源(逐时间戳 IC 序列的 Newey-West?按日 IC 的 t 检验?块 bootstrap?),给出它所用的实际样本数。在此之前,"显著为负"只能写成"点估计为负,显著性待对账"。

**即使显著,经济量级也可以忽略。** `E[R_头部20%] ≈ IC × σ_R(h) × 1.40`。h=1(一根 15m)的 `σ_R` 约 0.3–0.5(单根收益相对 0.7% 的止损):

```
−0.0281 × (0.3 ~ 0.5) × 1.40 ≈ −0.012 ~ −0.020 R   (约 1bp)
```

对比 v2 的"择时 −0.07R"和 20bps 的往返成本,h=1 的 IC 在经济上不构成"择时层是负资产"的证据。**统计显著 ≠ 经济显著**。

**更可能的解释:短周期回吐,而非"分数是负资产"。** 六因子里 EMA、CCI、价格行为、伪 CVD(K 线涨跌方向投票)都在衡量"最近几根沿交易方向走了多远"。得分高 ≈ 刚刚发生了一次顺势冲击。顺势冲击之后的 1–4 根出现回吐(买卖价差反弹、冲击消化),是短周期收益序列的常见特征,签名正是 v2 看到的:**h=1–4 为负、h≥8 衰减到不显著**。区分两种解释的检验见第二节 Q2。

### 1.4 组件 IC 的成本污染

v2 §1.5:RR 与 `stop_pct` 的 ρ=+0.737,与 `cost_R` 的 ρ=−0.682,所以其 IC +0.253 被判为"成本代理"。这个判断我倾向于同意,但**它的推论比 v2 写的更广**:

- 若 IC 是对 `R_net = R − 0.002/stop_pct` 计算的(+0.253 的量级只能这样解释),则**所有组件的 IC 都混入了"组件与止损宽度的相关"**。与止损宽度负相关的组件(选中窄止损 → `cost_R` 高 → `R_net` 低)会机械地得到负 IC。
- v2 §1.7 的表显示毛 `E[R]` 随止损变宽**下降**(0.0112 → 0.0052)。若 RR 分与止损宽度正相关,RR 对**毛 R** 的 IC 应当为**负**,而不是 +0.25——两者的符号相反,这本身就说明 +0.25 来自成本项。
- 因此"删除候选"那四个 4/4 为负的组件(cci、fib、pa、cvd)**没有被证明无效,只是被证明与成本几何相关**。在毛 R 与偏相关口径下重算之前,这个列表不应指导任何删除动作。

**修法(T0c):** ① 用毛 R(及方向符号化的 bps 收益)算 IC;② 对 `stop_pct`/`cost_R` 做偏相关;③ 控制"沿交易方向的过去 1–4 根收益"做偏相关(检验回吐假说);④ 逐时间戳横截面。

### 1.5 R 单位与"止损内生性":G0 与 §1.7 的共同盲点

R 单位下,边际与成本**同比例缩放**:

```
E[R_net] = (gross_bps − cost_bps) / stop_bps
```

分子是以 bps 计的"每笔毛收益 − 每笔成本",分母只是缩放因子。**止损宽度不改变分子的符号**;它只通过"持仓时间更长 → 毛收益累积更多"这条路径间接影响分子。v2 §1.7 看到的"`E[R]` 随止损变宽单调下行,恰好抵消 `cost_R` 的下降"正是这个恒等关系:`E[R]` 与 `cost_R` 都 ∝ 1/stop,而 8h 窗口内的毛收益 bps 并没有随止损增大。

对 G0("cost/R ≤ 0.10")的含义:

1. **G0 是结构筛选,不是盈利门。** 它保证成本在 R 单位上小,但没有保证毛边际在 R 单位上同样大。
2. **G0 在 15m 上几乎是"永不交易":** 97.4% 的决策 cost/R > 0.10,只有约 2.6% 通过(止损 ≥2%,即 ATR 处于极高分位)。
3. **G0 恰好选中滑点最大的时段。** 高波动期的滑点与冲击成本显著高于平均,而成本模型是常数 20bps(以及 v2 里的 12bps)。**G0 筛出的样本,其真实成本被系统性低估。**

建议改用 **bps 口径**:`G0′:预期毛收益(bps)≥ 2 × 往返成本(bps)`,且成本按波动率/流动性分层(滑点 ∝ σ)。

### 1.6 TL;DR #5 的算术:持平,不是盈利

> "成本压到 0.07 时,需要的边际正好是我们测出来的方向 edge(≈0.07R)"

在中位止损 0.68% 下:

| R 单位 | bps 等价 |
|---:|---:|
| 0.07R | **4.8bps** |
| 0.10R | 6.8bps |
| 0.18R(12bps 档) | 12.2bps |
| 0.27R(20bps 档) | 18.4bps |

"成本 0.07R"≈4.8bps 往返。Binance 普通用户的 maker 费率 0.02%/边,往返 4bps,**且不含滑点与逆向选择**;也就是说,全 maker、零滑点、零逆向选择才能达到"持平",而持平不是盈利。即便方向 edge 为真,在现实成本(≥7bps 混合执行、10bps 纯 taker、20bps 含滑点)下,它距离盈亏平衡还差 1.5–4 倍。**TL;DR #5 应改写为:"即使方向 edge 成立,也需要接近不可达的成本才能持平。"**

### 1.7 分解是定义式,不是检验

`择时 := 实盘 E[R] − 安慰剂 E[R]`,`成本 := −0.2728`,方向 := 安慰剂 E[R]。三项相加必然等于实盘 `E[R_net]`,所以"三者相抵后正好是 −0.27R"**不提供任何证据**。唯一可检验的内容是"安慰剂是否有效",即第 1.2 节。v2 §6.0 已意识到这一点,但 TL;DR #4 的措辞("真正的资产在方向")仍然过强。

## 二、Q1–Q6 逐条回答

### Q1:"方向 +0.07 / 择时 −0.07 / 成本 −0.27"成立吗?

**目前不接受。** 接受的条件(全部满足):

| 条件 | 判据 |
|---|---|
| ① 按 `t′−t` 符号拆分后,`t′>t` 的桶 `E[R]` 显著为正 | 95% 区间下界 >0;不是只在 `t′<t` 的桶里为正 |
| ② 构造 B(自洽规则 + 随机择时)的毛 `E[R]` > 0 | 同上,且按 (标的, 日) 聚类 |
| ③ 实盘与安慰剂的 `stop_pct` 分布同质 | KS 检验不拒绝;或做分层后各层同号 |
| ④ 聚类后的置信区间仍排除 0 | 按 UTC 日(及标的)分块 bootstrap |

**否掉的条件:** ①不满足(正效应只在 `t′<t`)即判定为前视泄漏,方向 edge 与择时项**同时作废**,此时 v2 §6.0 已写好的结论成立——"该策略应停止,不是重构"。我的先验是这种情形更可能,但需要 T0a-0 来确认。

### Q2:IC=−0.0281(q=0,neff 2,856)足以判定"择时层是负资产、应当删掉"吗?

**不足以。** 三个理由,以及区分"回吐"与"负资产"的检验:

1. **显著性未对账**(第 1.3 节)。在 neff=2,856 下 t≈−1.5。
2. **经济量级约 1bp**,不是 −0.07R。h=1 的负 IC 与 8h 口径的"择时 −0.07R"在数量级上对不上,二者不应互相引为证据。
3. **签名更像回吐。** 区分检验:

| 检验 | 预期:回吐假说 | 预期:分数本身是负资产 |
|---|---|---|
| 控制"沿方向的过去 1–4 根收益"后的偏相关 IC | **IC 消失或大幅缩小** | 基本不变 |
| 按"过去 4 根沿方向的涨幅"分桶,桶内看分数的 IC | 桶内 IC≈0 | 桶内仍为负 |
| IC 随 h 的曲线 | h=1–4 负、之后回到 0 | 全周期同号或递增 |
| 用方向符号化的 bps 收益(而非 R)重算 | 同号但幅度很小 | — |

**还有一个与重构直接相关的推论:** 若回吐假说成立,**v2 §5 的 DirectionCore(②"通道/结构突破 → 方向")会复制同样的问题**——突破入场是最典型的"顺势冲击之后入场",会继承同一个短周期回吐拖累,即新核里的"择时层"并没有被删掉,只是换了名字。所以"删掉择时层"应落实为**"入场时点与价格事件解耦"**(例如按固定节奏调仓),而不是"换一种事件触发"(第三节 3.4)。

### Q3:ρ=+0.737 把 +0.25 判为成本代理是否过度?

**不过度,但证据要补。** 判断依据:RR 分与止损宽度正相关,而 v2 §1.7 显示毛 `E[R]` 随止损变宽下降,所以 RR 对毛 R 的 IC 应当为负;+0.25 的符号与此相反,只能来自成本项。要把这个判断变成证据,做偏相关:

```
IC_partial = Spearman( RR_score , R_gross | stop_pct , cost_R )
```

如果偏相关后 IC 为 0 或为负,"成本代理"成立。如果仍有一部分正信息(例如 1/3),它也不应进入方向评分:因为 R 口径下信息量与止损宽度混杂,无法区分是"RR 几何有信息"还是"宽止损 = 高波动期的一种代理"。

**"RR 只作准入过滤"的含义:** RR 分与止损宽度高度相关,而止损 = `clamp(1.5×ATR, 0.5%, 3%)`,所以"RR 分高"≈"ATR 高"≈"高波动期"。把它当准入门,等价于"只在高波动期交易",与 DirectionCore 的①(波动率状态分层)**重复**,而且会把交易推向滑点最大的时段(第 1.5 节)。建议**不要通过 RR 分间接实现成本门**,直接用 `stop_pct`(或更好的,预期毛 bps 与成本 bps 之比)做门,并命名为成本门。

### Q4:4h 上做统计判断不可能——"提周期 + 重算因子"本质上不可验证吗?该选 1h 粗化还是等 2 年?

**两个都不选;约束是自设的。** 两点:

- **"1h 粗化 → 4 倍样本"只在策略周期本身就是 1h 时成立。** 若标注窗口仍是 4–8h,1h 重叠窗口之间没有新的独立信息;独立样本量由"日历时间 × 有效标的数 ÷ 持仓时长"决定,与 bar 粒度无关。
- **日志只有 8 周,但价格与资金费历史不受这个限制。** 因子可以直接在原始 bar 上重算,不需要决策日志。公开历史数据站提供多年期 U 本位合约 K 线与资金费文件(请先确认品种/时间范围可用、网络可访问)。

在"每个有效标的每个持仓周期一个独立片段、有效标的数取 4(加密高度相关,这是假设)"下:

| 历史长度 | 1d 持仓:neff | 最小可检测 `E[R]`(σ=1) | 4h 持仓:neff | 最小可检测 `E[R]` |
|---:|---:|---:|---:|---:|
| 8 周(现状) | 220 | 0.17 | 1,320 | 0.068 |
| 1 年 | 1,460 | 0.065 | 8,760 | 0.027 |
| 2 年 | 2,920 | 0.046 | 17,520 | 0.019 |
| 3 年 | 4,380 | 0.038 | 26,280 | 0.015 |
| 5 年 | 7,300 | 0.029 | 43,800 | 0.012 |

(MDE=2.485/√neff,单侧 5%、80% 功效;4h 行假设持仓之间近似独立,实际应以块 bootstrap 的有效数替换。)**2–3 年历史就能把 1d/4h 周期的 MDE 压到 0.02–0.05R**,足以判定 v2 关心的 0.07–0.10R 级别的边际。注意三点:**幸存者偏差**(用今天的 16 个标的回看历史)、**资金费必须入账**、**多年期包含多个 regime**,恰好可以检验 regime 依赖。

### Q5:G5 的"≥400 笔改参、≥1,000 笔切换"是否等于推迟到永远?

**如果它是唯一判据,是。** 达到统计功效所需的笔数:

| 要检出的毛边际 | 所需笔数(σ=1,80% 功效) | 以 66 笔/月计 |
|---:|---:|---:|
| 0.15R | 274 | 4.2 个月 |
| 0.10R | 618 | 9.4 个月 |
| 0.07R | 1,260 | 19 个月 |
| 0.05R | 2,470 | 37 个月 |

纸面前向交易**天然是慢的发现工具**。建议把"发现"和"确认"分开:

| 阶段 | 工具 | 判据 |
|---|---|---|
| 发现 | 历史 walk-forward / purged CV(≥2 年,≥2,000 个有效独立片段) | G1′(见第三节 3.3),并做多重检验校正 |
| 确认 | 前向纸面,预先登记的**序贯检验(SPRT)**:H0:毛边际 ≤ 成本门槛,H1:毛边际 ≥ 1.5×门槛 | 任一边界触发即停;平均样本量通常显著小于固定样本设计 |
| 执行完整性 | 前向纸面的成交/成本/延迟核对 | 与历史假设的偏差 <15%,与"盈利是否显著"无关 |

"R 分布 + 成本核算 + 机制解释"三件套可以作为**补充**(排除机制性错误),但不应替代数字判据。

| 序 | 风险点 | 为什么 |

## 三、对方案与协议的修改建议

### 3.1 把验证重心迁移到长历史

| 项 | v2 | 建议 |
|---|---|---|
| 数据 | 8 周日志(`2026-08 ~ 10`) | **新增 2–5 年公开历史**:K 线(15m 或 1h)、资金费;持仓量/多空比等衍生指标若可用也导入 |
| 因子 | 在日志里的决策行上评估 | 直接在原始 bar 上**重算**,不依赖决策日志;日志只用于执行层核对 |
| 标的 | 当前 14–16 个 | 当前集 + 在历史期内存在且流动性足够的标的,避免幸存者偏差;至少做"含/不含已下架标的"两个版本 |
| 成本 | 常数 20bps / 12bps | 分层:费率 + 随波动率缩放的滑点 + 资金费,三者分别入账 |
| 产出 | 4h/1d 阶段只出描述性报告 | 历史上可以出**判定性**结论(MDE 0.02–0.05R),前向纸面只做确认 |

### 3.2 修订后的零号实验(T0a′)

| 步 | 内容 | 工作量 | 判别点 |
|---|---|---|---|
| 0 | 安慰剂按 `t′−t` 符号与幅度分桶 | 10 分钟 | 泄漏 vs 持续性(第 1.2 节) |
| 1 | 干净安慰剂 A(陈旧方向,仅 `t′>t`)与 B(自洽规则 + 随机择时) | 半天 | 方向 edge 是否存在;择时项的真实大小 |
| 2 | KS 检验 + 按 (标的, UTC 日) 分块 bootstrap | 半天 | `stop_pct` 同质性;聚类后的 CI |
| 3 | IC 重算(T0c):毛 R / bps、偏相关(止损宽度、过去 1–4 根收益)、逐时间戳横截面;**披露 SE 来源与实际样本数** | 1–2 天 | 负 IC 是否存活;RR 与各组件的真实符号 |
| 4 | 分数洗牌安慰剂(日内洗牌分数分档,1,000 次) | 半天 | "无排序"与"被成本吃掉"的区分(同行建议已覆盖) |

**判决规则(事先写死):**

| 结果 | 动作 |
|---|---|
| B 的毛 `E[R]` 的 95% 区间包含 0,A 在 `t′>t` 桶不显著 | **方向 edge 作废**;停止"15m 策略重构",转入第 3.5 节终局评估 |
| A 显著为正(`t′>t`),B 不显著 | 方向有持续性但规则本身没有边际;只在更长周期上寻找(3.4) |
| B 显著为正且 ≥ 往返成本 bps 的 1.5 倍 | 候选 alpha,进入长历史复核(3.1)与多重检验 |
| 择时项显著为负且在回吐检验后仍在 | "入场时点与价格事件解耦"成为设计硬约束 |

### 3.3 门(G0–G5)的修订

| 门 | v2 | 建议 |
|---|---|---|
| G0 结构门 | cost/R ≤ 0.10 且资金费入账 | **G0′:预期毛 bps ≥ 2 × 往返成本 bps**;成本含波动率缩放的滑点与资金费;`stop_pct` 不进入判据 |
| G1 方向门 | 配对口径毛 `E[R]>0` 且 CI80 下界 >0,样本 ≥20,000 行 | **G1′:毛 bps 的 95% 单侧下界 >0(或 BH q<0.10,检验族包含项目历史所有已看过的假设)**,**以有效独立片段 ≥2,000 计,而不是行数**;历史上 ≥3 个互不重叠的时段符号一致 |
| G2 排序门 | `\|IC\|>MDE` 且 BH q<0.10 且符号为正 | 保留;**IC 必须基于毛 R/bps,并报告偏相关**;SE 来源与样本数必须披露 |
| G3 成本压力门 | 12bps / 20bps 两档 `E[R_net]>0` | 保留;**加一档"6–7bps 混合执行"并明确标注是否有成交率模型支持**;"4bps 全 maker"只作为理论上界,不作为通过条件 |
| G4 USDT 门 | R 口径改善 × 0.746 | **取消乘数**。0.746 是历史上 R 与 USDT 的比值,取决于各通道的单 R 风险,不是常数;改为"统一每 R 风险后直接按 R 评估",或逐笔以 `R × 当笔风险额` 计 USDT |
| G5 并行镜像 | ≥400 笔改参、≥1,000 笔切换 | **拆分为"发现(历史)/确认(前向 SPRT)/执行完整性"**(Q5);不再以单一笔数作闸门 |

**kill criteria 补充:** "任一信号族在 G1′ 或 G3 失败即整体废除"保留,并补一条**族级错误率控制**:候选族数 ≥3 时 G1′ 的显著性水平按族数校正;候选族与假设清单在跑之前冻结(带哈希入库)。

### 3.4 DirectionCore 的设计约束

| 约束 | 理由 |
|---|---|
| **时点中性** | 新核的入场时点相对"同一方向规则的随机时点"必须满足 lift 的 95% 下界 ≥0(构造 B 的对照)。否则视为复制了择时拖累 |
| **优先非事件触发的入场** | 按固定节奏(例如每日若干个固定 UTC 时点、或与资金费结算对齐)按当前方向调仓;这在构造上没有"择时层",且显著降低换手与成本。事件触发(突破)只在通过上一条检验后才允许 |
| **方向规则本身要在长历史上检验** | 1h 趋势追随的方向规则在 15m/8h 上没有理由有边际;应当在 4h–多日周期上重新测它的毛 bps |
| **成本门直接用 bps** | 不通过 RR 分间接实现(Q3) |
| **不输出排序分** | 同意 v2 的"方向 + 准入"两级输出;但"准入"只含成本门与波动率状态,不含任何打分 |

### 3.5 终局条件与日历时间盒

v2 有统计意义上的 kill criteria,**没有"全部失败之后做什么"和"最晚什么时候决定"**。建议写死:

| 项 | 建议 |
|---|---|
| 日历时间盒 | **6 周**:第 1 周完成 T0a′;第 2–4 周完成长历史导入与因子重算;第 5–6 周完成筛选与结论。到期无论结果如何都出 go / no-go 报告 |
| 全部候选失败时 | 停止 ≤4h 方向性 alpha 的搜索;二选一:(a)把资金费/基差类策略作为**独立项目**评估(需要现货腿与对冲模拟,当前纸面基础设施不支持,见下);(b)归档,保留日志与标注台作为研究资产 |
| 冻结 | 假设清单、成本模型、判据、候选族数在 T0a′ 之后、长历史实验之前**入库并打哈希**,之后只允许追加,不允许修改 |

**关于 T9(资金费 carry 第二腿):** carry 是"现货多 + 永续空"的对冲策略,需要现货腿、保证金与借贷模型;当前链路是"USDT 永续 dry-run,`submit()` 未实现"。若在永续单腿上"押注资金费方向",那是方向性策略,不是 carry,应走与其他候选相同的门。建议把 T9 的范围先收窄为**研究账本里的 carry 收益核算**,不并入主链。

## 六、验证矩阵

| 验证项 | 方法 | 通过标准 |
|---|---|---|
| 泄漏判别 | 安慰剂按 `t′−t` 分桶 | 报告各桶 `E[R]` 与区间;解读与第 1.2 节预测表一致 |
| 前视单测 | 对每条标注样本断言:方向所用的最大时间戳 ≤ 入场时点 | 全部通过;任何违例直接阻断出报告 |
| 安慰剂零假设 | 用**随机方向**(与价格独立)构造安慰剂 | `E[R] ≈ 0 ± 2×SE`;否则标注或安慰剂实现有偏差 |
| IC 的 SE 对账 | 同时报告 `1/√n_eff`、块 bootstrap、按日 t 检验三种 SE | 三者差异 <30%,否则以最保守者为准 |
| MDE 公式 | 单测:`MDE = (z_α+z_β)·σ/√n_eff` | 与解析值一致 |

## 附 B:对我 10-19 评审的更正

10-19 评审第 1.1 节为修复"基线与总体成本构成不匹配",我建议了配对安慰剂:"同标的、同日、同方向、同 `stop_pct`、随机 bar"(Task L1)。**这个构造有本文第 1.2 节指出的前视泄漏**:方向取自决策时点 `t`,而同日随机抽到的 `t′` 可能早于 `t`。我当时只考虑了成本构成一致,没有检查方向信息的时间方向,应当在建议时就指出并限定 `t′ ≥ t` 或在 `t′` 重新计算方向。v2 采用了这个构造并据此得到 +0.0704,所以 v2 的"方向 edge"部分源于我的建议。请以第 1.2 节的干净构造(A/B)替代 L1 的原始写法。
