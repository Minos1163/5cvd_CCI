## 2. 根因诊断：为何距离目标如此遥远

### 2.1 费用结构摧毁了所有 Edge

```
费用分析（Experiment C EMA Soft 为例）：

  毛利润      96.63   (116笔盈利交易的总回报)
  手续费    -121.90   (5bps × 2边 × 116笔)
  滑点      - 60.98   (5bps × 2边 × 116笔)
  净盈亏    - 86.25

结论：成本是毛利润的 1.89 倍。
即使胜率提升到 50%，成本结构下仍然亏损。

根本原因：2根K线合成出场（15m × 2 = 30分钟持仓）
  每笔交易总费用：约 0.20%（10bps手续费 + 10bps滑点）
  每笔平均毛回报：96.63 / 116 ≈ 0.83 USDT
  每笔平均费用：182.88 / 116 ≈ 1.58 USDT
  结论：平均每笔费用是毛利润的 1.9 倍 → 无论如何调参都无法盈利
```

### 2.2 胜率 25% vs 目标 80%：差距的来源

胜率 25% 意味着每 4 笔交易只有 1 笔盈利。这不是参数问题，是**系统性信号质量问题**。

```
EMA Soft（实验C）胜率分解：

  按方向:
    空头 77笔，胜率 31.17%   ← 勉强有方向性 Alpha
    多头 39笔，胜率 12.82%   ← 几乎没有 Alpha（随机水平以下）

  按模式:
    直接开仓 39笔，胜率 41.03%  ← 有效信号
    探针开仓 77笔，胜率 16.88%  ← 接近随机，严重拖累整体

诊断：
  多头信号在当前市场环境（30D窗口）缺乏基本有效性
  Probe 进场机制在当前参数下几乎等同于随机开仓
  77笔 Probe 亏损是整个策略亏损的主要来源
```

### 2.3 单标的分析：XRPUSDT 是最大负贡献

```
EMA Soft 标的表现（实验C）：

  BNBUSDT  28笔  +3.31  胜率 42.86%  ← 唯一正向标的
  SOLUSDT  28笔  -17.98 胜率 28.57%
  TRXUSDT  26笔  -9.15  胜率 19.23%
  XRPUSDT  28笔  -48.44 胜率 14.29%  ← 最大亏损来源
  尾部标的  各1-2笔，全部亏损

XRPUSDT 贡献了整个策略约 56% 的净亏损（-48.44 / -86.25）
策略若在 XRPUSDT 上完全停火，净亏损从 -86.25 降至 -37.81（改善 56%）
```

### 2.4 三大结构性瓶颈排序

```
瓶颈 #1（最致命）: 合成出场 → 费用 > 毛利润
  影响量级：如不解决，任何入场优化都无法使策略盈利
  所需行动：实现完整出场生命周期

瓶颈 #2（高优先）: Probe 进场胜率 16.88%
  影响量级：77 笔 Probe 贡献 -64.86 净亏损（占总亏损 75%）
  所需行动：禁用或大幅收紧 Probe 进场阈值

瓶颈 #3（中优先）: 多头信号几乎无效（12.82% 胜率）
  影响量级：39 笔多头贡献 -47.32 净亏损
  所需行动：分离多空阈值，暂时禁用多头或大幅提高多头门槛
```

## 3. 第一优先级：构建完整出场生命周期

### 3.1 为什么这是最高优先级

当前合成出场（2根K线后平仓）的根本缺陷：

```
问题 1：持仓时间固定 30分钟，导致两种失败：
  a. 好的趋势在 30 分钟后才真正启动 → 过早出场，错失利润
  b. 坏的信号在 30 分钟内亏损扩大 → 没有止损，让亏损持续

问题 2：固定出场不能区分"该跑"和"该拿"
  信号质量 0.85 和信号质量 0.55 的交易获得完全相同的持仓时间
  无法实现高分信号多拿、低分信号快跑

问题 3：费用是固定成本，合成出场无法通过延长持仓摊薄费用
  30分钟持仓：费用占回报比 > 190%（已证）
  假设 TP=3.0% 的完整出场：费用占回报比 ≈ 7%（可接受）
```

### 3.2 完整出场生命周期规格

```python
@dataclass
class ExitLifecycleConfig:
    # ── ATR 初始止损 ─────────────────────────────────────────
    atr_stop_period:      int   = 14        # ATR 计算周期
    atr_stop_multiplier:  float = 1.5       # 止损 = 入场价 ± 1.5× ATR
    # 强趋势允许宽松止损（给趋势呼吸空间）
    strong_trend_atr_mult: float = 2.0
    weak_trend_atr_mult:   float = 1.2

    # ── 三档止盈梯度 ──────────────────────────────────────────
    tp1_rr_ratio:    float = 1.5    # TP1 = 止损距离 × 1.5（部分平仓 40%）
    tp2_rr_ratio:    float = 2.5    # TP2 = 止损距离 × 2.5（部分平仓 35%）
    tp3_rr_ratio:    float = 4.0    # TP3 = 止损距离 × 4.0（剩余 25%）

    tp1_close_pct:   float = 0.40   # TP1 处平仓 40%
    tp2_close_pct:   float = 0.35   # TP2 处平仓 35%
    tp3_close_pct:   float = 0.25   # TP3 处平仓 25%

    # ── 保本调整 ──────────────────────────────────────────────
    breakeven_trigger_rr: float = 1.0   # 盈利达到 1× 止损距离后
    breakeven_buffer_pct: float = 0.001 # 止损调至入场价 + 0.1%（手续费保护）

    # ── 移动止损 ──────────────────────────────────────────────
    trailing_activate_rr: float = 1.5   # TP1 成交后激活移动止损
    trailing_atr_mult:    float = 1.0   # 移动止损跟随距离 = 1× ATR

    # ── 最大持仓时间 ──────────────────────────────────────────
    max_hold_bars:        int   = 32     # 15m × 32 = 8小时强制平仓
    timeout_exit_type:    str   = "MARKET"

    # ── 出场冷却（信号维度） ──────────────────────────────────
    loss_cooldown_bars:   int   = 16     # 亏损出场后该标的冷却 4小时
    win_cooldown_bars:    int   = 4      # 盈利出场后冷却 1小时
```

### 3.3 完整出场对费用结构的改善

```
假设：EMA Soft 116笔，完整出场下平均盈利持仓 = 20根K线（5小时）

完整出场场景（估算）：
  TP1（40%仓位，1.5RR）：约 2.25% 回报
  TP2（35%仓位，2.5RR）：约 3.75% 回报
  止损（仅亏损笔）：约 -1.5% 回报

每笔费用不变（0.20%），但毛回报大幅增加：
  胜利笔平均毛回报（加权TP）：约 2.8%（vs 当前 0.83%）
  费用占毛回报比：0.20% / 2.80% = 7.1%（vs 当前 190%）

这是本次修复中最重要的数字：
  从"费用是毛利润1.9倍"改善到"费用是毛利润的7%"
```

### 3.4 出场生命周期实现优先级

```
Phase A（最小可测试版本，2天工期）:
  → 仅实现 ATR 止损 + 单一 TP（1.5RR）
  → 去掉合成 2-bar 出场
  → 重跑实验 C 配置，观察期望值变化

Phase B（完整梯度，1周工期）:
  → TP1/TP2/TP3 三档
  → 保本调整
  → 移动止损

Phase C（智能出场，2周工期）:
  → EMA 斜率感知型移动止损（趋势越强，止损越宽）
  → 基于市场状态动态调整最大持仓时间
  → 基于出场结果的自适应冷却
```

## 7. 费用摩擦分析与最低 Edge 要求

### 7.1 盈亏平衡分析

```
固定假设（不可变）：
  手续费：5 bps / 每边 = 10 bps 单边
  滑点：  5 bps / 每边 = 10 bps 单边
  总回转成本：20 bps = 0.20% per trade

不同胜率 & 盈亏比下的损益平衡表：

  盈亏比 →      1.0x    1.5x    2.0x    2.5x    3.0x
  胜率 30%:    -0.200  -0.065  +0.040  +0.110  +0.160
  胜率 50%:    -0.200  +0.100  +0.300  +0.450  +0.600
  胜率 65%:    -0.200  +0.203  +0.530  +0.778  +1.008
  胜率 80%:    -0.200  +0.440  +0.840  +1.200  +1.520

  单位：% per trade（已扣除 0.20% 费用）

结论：
  当前状态（胜率 25%，无合理盈亏比） → 每笔预期亏损，无药可救
  目标（胜率 80%，盈亏比 1.5x） → 每笔期望 +0.44%，累计可观
  最低可行区间：胜率 ≥ 50% AND 盈亏比 ≥ 1.5x，才能覆盖费用
```

### 7.2 完整出场对盈亏比的改善路径

```
完整出场（ATR止损 + 三档TP）的理论盈亏比：

  假设 ATR 止损 = 0.8%（1.5x ATR on 15m）
  TP1 = 1.5RR = 1.2%（40% 平仓）
  TP2 = 2.5RR = 2.0%（35% 平仓）
  TP3 = 4.0RR = 3.2%（25% 平仓）

  加权平均胜利回报 = 0.40×1.2% + 0.35×2.0% + 0.25×3.2% = 1.98%
  止损回报 = -0.8%
  盈亏比 = 1.98 / 0.80 = 2.48x

  代入 65% 胜率：期望值 = 65%×1.98% - 35%×0.80% - 0.20% = +0.82%
  代入 50% 胜率：期望值 = 50%×1.98% - 50%×0.80% - 0.20% = +0.39%

重点：完整出场将目标胜率从 80% 降低到 50-65% 也能盈利
这是实现策略的最低成本路径
```

## 9. 滚动回测验证计划

### 9.1 为何不能依赖单一 30D 窗口

```
当前 30D 窗口的局限性：

  1. 小样本问题
     116 笔交易不足以区分技术 Alpha 和市场噪音（需 ≥ 400 笔）

  2. 市场状态偏差
     单个 30D 窗口可能全为熊市或横盘，导致结论不可泛化

  3. 标的组合不稳定
     XRPUSDT 在单一窗口内主导了负 Alpha，但其他窗口可能不同

  4. 验收标准必须基于多窗口：
     胜率 ≥ 55%（中间目标）在至少 4 个独立 30D 窗口中成立
     才能开始考虑提升至目标 80%
```
