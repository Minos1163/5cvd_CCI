| 验证 | 方法 | 结果 |
|---|---|---|
| 真实重放 | 1440 条 2026-11-13 决策，改动前后源码树对照 | `action` / `score` / `leverage` / `notional` **逐位相同** |

**为什么改 `use_ema_architecture: true → false` 是等价的**：
`entry_chain.py:366` 的 `if cfg.use_fib_pa_architecture:` **提前 return**，后面三处 `use_ema_architecture` 判定（EMA200 硬闸、EMA50 DIRECT/PROBE 最低分）在 fib_pa 架构下**从不执行**。同时 `run_live_dry_run.py:2787` 的预热下限 `max(warmup, 200 if use_ema else 240)` 在本配置下是 `max(240, 200)` vs `max(240, 240)` = 240，相同。

**这是代码+配置的原子对。** 只拉代码不改配置 → `resolve_architecture` 仍返回 fib_pa（枚举缺省 auto + fib_pa=true），行为不变；只改配置不拉代码 → `scoring_architecture` 是未知键，**启动即失败**。必须同批上、同批回。
